# Contributing to AgentR Awesome RSI

This index is an [AgentR](https://agentr.dev) research list. Edit `README.md` directly. Prefer primary sources and official implementations.

## Inclusion

Papers only, **2025–present**, and **at most ~30** entries. The work must be tightly about recursive self-improvement: a persistent object (code, harness, weights, memory, evaluator) is changed and reused in a later improvement round.

Out of scope: one-shot answer revision, generic agent frameworks, marketing posts, pre-2025 papers, and adjacent skill/memory methods that do not close an RSI loop.

## Format

```markdown
### [Article Title](https://arxiv.org/abs/....) — Organization
*YYYY-MM-DD · Source Type*

`Self-Evolving Agents` `Self-Modification`

> **Abstract:** Problem or context, method or system, and main reported result. Factual, technical, concise. No opinions, “why it matters,” or marketing language.
```

Use one or more of:

- `Self-Evolving Agents`
- `Self-Modification`
- `Self-Training`
- `Memory & Experience`
- `Scientific & Algorithmic Discovery`

Add a tag only if it describes the paper. Do not copy the full abstract. Do not report unverified performance claims.

One paper per pull request when practical. Confirm every link resolves.

## Safety

Do not contribute instructions for running self-modifying code with broad host access or production credentials.
